# VOICE FIT — 말로 기록하는 AI 운동 도우미

운동 중에는 손에 땀이 나고 기구를 잡고 있어서 폰을 만지기 어렵습니다. **VOICE FIT**은 이어폰·헤드셋 마이크로 **말만 해서** 운동을 기록하고 휴식 시간을 관리하는 앱입니다.

> "스쿼트 열두 개" → 기록 · "휴식 60초" → 타이머 · "아까 기록 열 개로 고쳐" → 수정 · "운동 끝" → 결과 요약

- **웹(PWA):** https://voice-fit-teal.vercel.app (화면을 바로 체험할 수 있어요. 전화 응대는 시연 모드)
- **안드로이드 앱:** 화면이 꺼져도 듣기, 잠금화면 위 대답, 전화 응대까지 모든 기능이 동작합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 음성 명령 인식 (MUST 1) | 자연스러운 문장을 알아듣고, 확신도 70% 미만이면 실행하지 않고 되묻기. 마이크 장치(유선·블루투스) 선택 |
| 운동 기록·휴식 관리 (MUST 2) | 횟수·세트·라운드·시간 기록(1~1000), 휴식 타이머(10~300초)와 음성 알림, "취소"·"고쳐" |
| 결과·기록 확인 (NICE 1) | 운동 종료 후 요약, 과거 기록 조회, "이번 주 스쿼트 몇 개 했어?" 같은 질문에 저장된 기록만으로 답변 |
| 호출어로 부르기 (NICE 2) | 화면이 꺼지거나 잠겨 있어도 호출어를 부르면 "네, 말씀하세요" |
| 운동 중 전화 응대 (NICE 3) | 건 사람 이름 읽기, 말로 받기·끊기, 확인받은 뒤에만 문자 남기기 |
| AI 목소리 | 기본 꺼짐. 홈의 "AI 목소리" 버튼으로 언제든 켜고 끄기 (추가 사용료) |

## 개인정보와 API 키

- 회원가입·서버가 없습니다. 운동 기록은 **사용자 기기 안에만** 저장되고, 음성 녹음 파일은 저장하지 않습니다.
- 이 저장소와 배포된 웹에는 **개발자 API 키가 들어 있지 않습니다.** AI 기능을 쓰려면 각 사용자가 앱 설정의 "AI 연결"에 자기 OpenAI 키를 넣습니다(그 기기에만 저장). 키가 없어도 기본 기록·휴식 기능은 기기 안 해석기로 동작합니다.
- 외부로 보내는 내용은 앱 설정의 "외부로 전송되는 내용"에 안내합니다.

## 실행 방법

```bash
npm install
npm test               # 자동 테스트 (81개)
npm run dev            # 웹 화면: http://localhost:3000
```

안드로이드 앱 빌드 (Android Studio 필요):

```bash
npx cap sync android
cd android && ./gradlew assembleDebug
```

HTML·CSS·JavaScript(프레임워크 없음) · Capacitor 8(안드로이드) · Java 안드로이드 플러그인(백그라운드 듣기, 마이크 연결, 전화) · Vercel(정적 웹 배포)
