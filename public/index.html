    설정

    마이크 장치

    운동할 때 쓸 마이크를 골라요. 블루투스 이어폰·유선 헤드셋은 먼저 폰에 연결하면 목록에 나와요. 고른 마이크는 기억하고, 연결이 끊기면 휴대폰 마이크로 이어서 들어요.

    지금 듣는 마이크확인 중

    블루투스 이어폰 마이크를 쓰면 듣는 동안 이어폰이 통화 모드로 바뀌어 안내 음성 음질이 잠깐 낮아질 수 있어요. 마이크를 바꾸면 내 목소리 등록도 그 마이크로 다시 해 주세요.

    외부로 전송되는 내용

    • 음성 인식: 자동 모드에서 OpenAI 키가 있으면 일반 대화 녹음을 OpenAI로 보내 인식해요. 호출어 대기와 실시간 카운트는 기기 음성 인식 서비스를 사용해요.
    • 내 OpenAI 키를 넣은 경우: 현재 문장, 최근 대화 최대 8개와 직전 운동 기록이 의도 해석을 위해 OpenAI로 전송돼요. 목소리 등록 녹음도 품질 확인에 사용돼요. 자연스러운 AI 음성을 켜면 답변 문장도 음성 생성에 전송되며 사용량에 따라 과금돼요.
    • 저장: 음성 녹음 파일은 저장하지 않아요. 운동 기록·API 키·목소리 지문은 이 기기에만 저장돼요.

    호출어

    이 말을 하면 VOICE FIT 이 대답하고 운동을 물어봐요.

    현재 호출어: 없음

    주변 소리 배제

    오버워치의 ‘음성 감지 기준’처럼, 기준선보다 작게 들어온 소리(TV·음악·멀리 있는 사람 목소리)는 무시하고 폰 가까이서 말한 내 목소리만 받아요.

    말해 보면 막대가 움직여요. 내 목소리는 기준선을 넘고, 주변 소리는 넘지 않게 맞추세요.

    내 목소리만 듣기

    기기 인식에서 등록한 음색을 기준으로 소리를 거르는 실험 기능이에요. 조용한 발음까지 잘라낼 수 있어요. OpenAI 일반 대화에서는 문장 보존을 위해 이 필터를 적용하지 않으며, 주변 사람의 말도 들어올 수 있어요. 화자 인증 기능은 아니에요.

    등록 상태확인 중

    AI 연결 (내 OpenAI 키)

    내 OpenAI API 키를 넣으면 AI 가 말을 더 똑똑하게 알아들어요. 키는 이 기기에만 저장되고 VOICE FIT 서버로는 보내지 않아요. 요금은 키 주인의 OpenAI 계정에서 나가요. 키가 없으면 오프라인 해석으로 동작해요.

    현재 키확인 중

    키 발급: platform.openai.com → API keys. 공용 컴퓨터의 브라우저에는 키를 저장하지 마세요.

    홈 화면에서도 호출

    다른 앱을 쓰거나 홈 화면에 있어도, 화면이 꺼져 있어도 호출어를 부르면 짧은 신호음과 함께 화면이 켜지고 잠금화면 위에서 바로 대답해요. 대화가 끝나면 원래 화면(잠금화면)으로 돌아가요. 운동 중 화면이 꺼져도 카운트·타이머는 계속돼요.

    다른 앱 위에 표시확인 중
    알림확인 중

    켜면 화면이 꺼져 있어도 호출을 놓치지 않아요(배터리는 조금 더 써요). 끄면 안드로이드 설정 화면이 열려요 → 배터리 → 최적화를 고르면 돼요.

    상태확인 중

    전화 응대

    운동 중 전화가 오면 이름(없으면 번호)을 읽어 주고, 받기·끊기·문자 남기기를 말로 고를 수 있어요.

    권한 상태확인 중

    웹 브라우저는 실제 전화를 다룰 수 없어서 시연 모드로 동작해요. 안드로이드 앱에서는 실제 전화를 감지하고 받기·끊기·문자 전송까지 해요.

    테마

    음성

    기본은 꺼져 있어요. 켜면 답변 문장이 OpenAI로 전송되고 사용량만큼 내 키로 과금돼요. 홈의 ‘AI 목소리’ 버튼으로도 언제든 켜고 끌 수 있어요. AI가 생성한 목소리예요. 연결이 안 되면 기기 목소리로 안내해요. 카운트·타이머 알림은 빠른 기기 목소리를 사용해요.
